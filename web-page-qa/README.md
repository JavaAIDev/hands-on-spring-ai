# RAG with Web Page

## Add web page

Go to [Swagger UI](http://localhost:8080/swagger-ui/index.html) and call the `/etl/webpage` API to add a web page. Content of this web page will be added to the vector store.

## Chat with LLM

Go to [Chat Agent UI](http://localhost:8080/webjars/chat-agent-ui/index.html) and ask questions about the newly added page.
