# Spring AI Observability

Spring AI Observability using [Langfuse](https://langfuse.com/) and [MLflow](https://mlflow.org)

[![build](https://github.com/JavaAIDev/spring-ai-observability/actions/workflows/build.yaml/badge.svg?branch=main)](https://github.com/JavaAIDev/spring-ai-observability/actions/workflows/build.yaml)
